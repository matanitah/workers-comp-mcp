# Workers' compensation, state by state

Research bundle for a FastMCP server that returns, for a jurisdiction, the current regulations word for word and the reimbursement record. This folder is the research record.

* [Methodology](/methodology) - How this bundle treats official regulations, benefit caps, and ClaimCalc injury settlements.
* [Reimbursement record](/reimbursement-schema) - JSON object for each jurisdiction. Benefit caps and fee-schedule maximums are the record. Injury-level settlement amounts are the ClaimCalc object.
* [Countrywide claim costs](/countrywide-claim-costs) - National workers' compensation claim-cost highlights for 2023-2024. They are not a state reimbursement rate and they are not a complete injury table.

# States

* [States](/states/index) - Fifty states and the District of Columbia. Each concept links to a reimbursement JSON file.
